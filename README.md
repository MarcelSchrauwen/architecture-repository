## Architecture Repository
*Zoals de titel weergeeft is dit een Architecture Repository, oftewel een plek om architectuur dingen op te slaan.*

### Wat is het?
Deze repository is een op TOGAF gebaseerde en op maat gemaakte opslagplek van enterprise architectuur gericht op zorg-, sociale-, en publieke dienstverlening in het kader van gezondheid.

### Voor wie is het bedoeld?
Vooral voor mijzelf. Maar wees welkom om rond te kijken als je daar de tijd voor wilt nemen.

### Waarom al die moeite?
In de eerste plaats - gewoon omdat ik het leuk vind om te doen. In de tweede plaats omdat ik een plek nodig heb waar ik volledig controle over heb en alles in kan stoppen wat ik zelf wil. Ik heb deze plek nodig om het gezondheidsinformatiestelsel zo goed mogelijk te begrijpen in het kader van mijn dagelijkse werk. Een persoonlijke kennisbank dus eigenlijk. Maar dan in architectuurvorm.

### Wanneer?
Volledig in mijn vrije tijd.

### Hoe?
Een in beton gegoten werkwijze heb ik niet maar momenteel ben ik bezig met het vullen van de repo met Europese en Nederlandse wet- en regelgeving.
