Standards Library ()

De Standards Library bevat juridische, organisatorische, semantische en technische afspraken en specificaties die zijn opgenomen in de architectuur. Veel van deze standaarden vereisen een nadere invulling voordat zij binnen de eigen context kunnen worden toegepast.

TOGAF definitie: The Standards Library captures the standards with which new architectures must comply, which may include industry standards, selected products and services from suppliers, or shared services already deployed within the organization.
