Architecture Repository ()

Dit model richt zich in eerste instantie op wet- en regelgeving. Om deze scope te duiden wordt het TOGAF Architecture Repository ontwerp gehanteerd. Wetten en regels bevinden zich in de group "External Standards" en hebben daarmee effect op wat er mogelijk opgenomen wordt in de Standards Libary van de (enterprise). De Standards Library moet daarmee ruimer geïnterpreteerd worden dan enkel technologie standaarden.

In een volgende iteratie wil ik het gehele model graag verder invullen met overige onderwerpen die betrekking hebben op het gezondheidsinformatiestelsel. Als experiment wil ik bijvoorbeeld onderzoeken of je een architectuur zou kunnen afleiden uit wetten en regels.
