# Architecture Repository
*Zoals de naam al aangeeft is dit een Architecture Repository: een centrale plek voor het vastleggen, organiseren en onderhouden van architectuurkennis.*

## Wat is het?
Deze repository is een op TOGAF gebaseerde en op maat ingerichte opslagplaats voor enterprise-architectuur. De focus ligt op zorg-, sociale- en publieke dienstverlening binnen het gezondheidsdomein.

## Voor wie is het bedoeld?
Deze repository is in eerste instantie opgezet voor eigen gebruik, maar anderen zijn van harte welkom om de inhoud te verkennen en er inspiratie uit te halen. De bedoeling is niet dat uitwerkingen, modellen of teksten uit deze repository worden overgenomen. Gebruik daarvoor de oorspronkelijke bronnen waarnaar wordt verwezen en maak op basis daarvan een eigen interpretatie en uitwerking.

## Waarom al die moeite?
Omdat ik het leuk vind om te doen.<br><br>
Daarnaast wilde ik een plek creëren waar ik volledige controle heb over de inhoud, structuur en ontwikkeling. Een omgeving waarin ik kennis kan vastleggen en uitwerken in mijn eigen tempo, onafhankelijk van andere prioriteiten of agenda's.<br><br>
Deze repository helpt mij om het gezondheidsinformatiestelsel beter te begrijpen in het kader van mijn dagelijkse werkzaamheden. Je kunt het zien als een persoonlijke kennisbank, maar dan vormgegeven als een architectuurrepository.

## Hoe?
Door kennis, inzichten en referentiemateriaal die ik in de afgelopen jaren in mijn vrije tijd heb verzameld, samen te brengen, te structureren en actueel te houden.<br><br>
Omdat ieder architectuurinitiatief ergens moet beginnen, ligt het zwaartepunt momenteel bij de Reference Model en Standards Library. Vanuit deze basis wordt de repository verder uitgebreid en verfijnd.
